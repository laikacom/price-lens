演示引擎

淘宝与京东都没有公开的历史价格接口。本应用内置一个可复现的行情模拟器： 同一个链接每次生成的曲线完全一致，用来演示界面、统计口径与判断逻辑。

  • 当前价、历史最低、波动幅度都是模拟值，不是真实行情
  • 导入真实数据或接入接口后，结论才有参考价值
  • 模拟曲线包含 618 / 双11 / 年货节等大促区间

导入真实数据

支持 CSV（日期,价格，一行一条）或 JSON。导入后会替换当前商品的曲线。

接入真实接口

在页面里定义 window.PRICE_LENS_FETCH，之后每次查询会优先调用它；失败则回退到演示数据。

window.PRICE_LENS_FETCH = async (info) => {
  // info = { platform, id, url }
  const r = await fetch(
    'http://127.0.0.1:8787/api/history?url=' +
    encodeURIComponent(info.url));
  const j = await r.json();
  return j.series;
  // [{ date: '2026-05-01', price: 1299 }, ...]
};
